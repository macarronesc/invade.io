# invade.io — Google Play (Русский)

## Название приложения (9/30)

```
invade.io
```

## Краткое описание

```
Захватывайте территории база за базой. Быстрая стратегия, офлайн, без рекламы.
```

## Полное описание

```
invade.io — быстрая территориальная стратегия: выберите базу, проведите пальцем, и войска отправятся к следующей. Пять секунд на понимание, 30 уровней кампании и более 100 фронтов вторжения.

Карта — настоящий мир с берегами, границами и более чем тысячей городов. Каждый континент добавляет правило: столицы, фабрики, джунгли, оазисы, крепости и морские пути. Пройдите кампанию, чтобы открыть региональные вторжения с тремя фронтами, звёздами и финальным боссом.

Вас ждут ежедневные испытания со сменяющимися правилами и свободные завоевания в экспедициях из пяти регионов. Играйте офлайн, без рекламы и покупок: золото зарабатывается в игре. 15 языков, светлая и тёмная темы, палитра для дальтоников, уменьшенная анимация и настраиваемая вибрация.
```
