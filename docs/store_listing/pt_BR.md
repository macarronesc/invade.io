# invade.io — Google Play (Português do Brasil)

## Nome do app (9/30)

```
invade.io
```

## Descrição curta

```
Conquiste territórios base por base. Estratégia rápida, offline e sem anúncios.
```

## Descrição completa

```
invade.io é um jogo de estratégia territorial rápido: escolha uma base, arraste o dedo e suas tropas marcham para a próxima. Cinco segundos para entender, 30 níveis de campanha e mais de 100 frentes de invasão para dominar.

O mapa é o mundo real, com costas, fronteiras e mais de mil cidades. Cada continente adiciona uma regra: capitais, fábricas, selva, oásis, fortalezas e rotas marítimas. Complete a campanha para abrir invasões regionais de três frentes, com estrelas e um chefe final.

Há também desafios diários com regras rotativas e conquista livre em expedições de cinco regiões. Jogue offline, sem anúncios e sem compras: o ouro é conquistado jogando. 15 idiomas, temas claro e escuro, paleta para daltonismo, movimento reduzido e vibração ajustável.
```
