# invade.io — Google Play (한국어)

## 앱 이름

```
invade.io: 영토 전략
```

## 짧은 설명

```
실제 세계 지도에서 영토를 정복하세요. 광고 없는 오프라인 전략 게임
```

## 전체 설명

```
하나의 기지에서 시작해 6개 대륙으로 정복을 넓혀 보세요.

invade.io는 실제 세계 지도를 무대로 하는 오프라인 싱글 플레이 영토 전략 게임입니다. 기지 사이를 드래그해 병력을 보내고, 아군을 모아 공격하거나 후퇴할 시점을 결정하세요.

한 수마다 달라지는 전투
공장을 점령해 병력을 빠르게 모집하고, 중요한 수도를 확보하고, 요새 방어선을 돌파하세요. 정글, 오아시스, 바닷길, 지원군을 받는 보스 등 대륙마다 다른 전술이 필요합니다. 한 번의 드래그로 여러 아군 기지를 연결하거나 이동 경로를 끊어 병력을 불러올 수 있습니다.

캠페인 너머로 이어지는 정복
6개 대륙에 걸친 30개 캠페인 스테이지에 도전하세요. 각 대륙의 캠페인을 완료하면 해당 대륙의 지역 침공이 열립니다. 36개 지역과 108개 전선에서 별을 모으고, 지역 완료로 골드를, 대륙 정복으로 외형 보상을 얻으세요.

자유 정복에서는 한 번의 원정이 5개 지역으로 구성되며 마지막에 보스와 싸웁니다. 일일 도전은 전투 업그레이드 없이 동일한 초기 병력과 매일 바뀌는 규칙으로 진행됩니다. 개인 최고 기록을 경신하고 결과 카드를 복사해 친구에게 공유하세요. 일일 도전은 기기 안에서 진행되며 실시간 플레이어 대전이 아닙니다.

플레이로 쌓는 성장
수비대, 병력 모집, 행군 속도, 골드 보상을 업그레이드하세요. 계급을 올리고 도감에 캠페인 도시를 모으며 20개 업적을 달성하세요. 군대 색상, 기지 모양, 부대 스타일, 지도 테마도 해제할 수 있습니다. 외형 아이템은 모습만 바꾸며 전투력에 영향을 주지 않습니다.

나에게 맞는 플레이
• 오프라인 플레이, 광고 없음, 인앱 구매 없음. 골드는 플레이로 획득합니다.
• 한국어를 포함한 15개 언어를 지원하며, 아랍어는 오른쪽에서 왼쪽으로 표시됩니다.
• 밝은 테마와 어두운 테마, 글자 크기, 색각 보조 팔레트, 동작 줄이기, 지도 대비, 게임 속도, 진동을 조절할 수 있습니다.
• 계정이 필요 없습니다. 진행 상황은 기기에 저장되며 백업 내보내기와 가져오기가 가능합니다. 클라우드 저장은 없습니다.

개인정보 보호
사용 통계와 오류 보고는 선택 기능이며 이 버전에서는 기본적으로 켜져 있습니다. 설정 → 개인정보 보호에서 각각 끌 수 있으며 저장된 선택은 유지됩니다. 게임 플레이 자체에는 인터넷 연결이 필요하지 않습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.
```
