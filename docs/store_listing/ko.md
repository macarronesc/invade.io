# invade.io — Google Play (한국어)

## 앱 이름 (9/30)

```
invade.io
```

## 짧은 설명

```
기지를 하나씩 점령해 영토를 정복하세요. 빠른 전략, 오프라인, 광고 없음.
```

## 전체 설명

```
invade.io는 기지를 고르고 손가락으로 끌어 다음 기지로 군대를 진군시키는 빠른 영토 전략 게임입니다. 5초면 이해하고, 30개 캠페인 레벨과 100개 이상의 침공 전선을 공략할 수 있습니다.

지도는 실제 세계이며 해안선, 국경, 1,000개 이상의 도시가 등장합니다. 대륙마다 수도, 공장, 정글, 오아시스, 요새, 해상 항로 같은 규칙이 더해집니다. 캠페인을 완료하면 3개 전선, 별, 최종 보스가 있는 지역 침공이 열립니다.

규칙이 바뀌는 일일 도전과 5개 지역 원정의 자유 정복도 즐길 수 있습니다. 오프라인 플레이, 광고 없음, 결제 없음. 골드는 플레이로 얻습니다. 15개 언어, 라이트/다크 테마, 색약 팔레트, 동작 줄이기, 진동 조절을 지원합니다.
```
