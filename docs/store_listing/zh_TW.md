## Short description

```
征服真實世界地圖。離線領土策略遊戲，無廣告
```

## Full description

```
把一座基地，擴張成橫跨大陸的征服之路。

invade.io 是一款離線單人領土策略遊戲，戰場就是真實世界的地圖。在基地之間拖曳即可派兵，合併兵力，並決定何時進攻、何時撤退。簡單的操作，讓下一步完全由你掌控。

每一步都舉足輕重
佔領工廠加快徵兵、掌握戰略首都，並突破重重防禦。不同大陸各有叢林、綠洲、海上航線，以及會獲得增援的 Boss。一筆劃連結多座己方基地，或切斷路線召回你的部隊。

戰役，以及更多挑戰
征服六大洲的 30 個戰役關卡。完成各大陸的戰役後，即可解鎖區域入侵：59 個區域、177 條戰線，以及等著你拿滿的星星。完成區域可獲得金幣，完成大陸則能解鎖外觀獎勵。通關戰役後，可攀登九個晉升層級，在更強的對手、額外金幣與新升級加持下重玩全部 30 張地圖。

更多征服方式
踏上自由征服的遠征：每次遠征涵蓋五個區域，最後以 Boss 作結。挑戰規則輪替、起始兵力相同且無戰鬥升級的每日挑戰。刷新個人紀錄，並複製成績卡分享給朋友。每日挑戰在本機進行，不會對上真人玩家。

玩出來的成長
升級駐軍、徵兵、行軍速度與金幣獎勵。提升軍階，在圖鑑中收集戰役城市，並完成 28 項成就。解鎖軍隊顏色、基地形狀、部隊樣式與地圖主題。外觀道具只改變軍隊的樣貌，不影響戰力。

照你的方式玩
• 離線遊玩，無廣告、無內購。金幣靠遊玩獲得。
• 支援 {count} 種語言：{languages}。阿拉伯語提供由右至左的介面。
• 淺色與深色主題、可調整文字大小、色盲友善配色、減少動態效果、地圖對比度、遊戲速度與觸覺回饋。
• 不需要帳號。進度保存在你的裝置上，並可匯出與匯入備份；沒有雲端存檔。

開放原始碼
invade.io 免費，並以 Apache-2.0 授權開放原始碼。你可以直接在瀏覽器試玩：macarronesc.github.io/invade.io/play/，也可以在 github.com/macarronesc/invade.io 閱讀、Fork 並改進程式碼。

隱私
使用統計與當機報告為選用項目，在此版本中預設開啟。你可以在「設定」→「隱私」中分別關閉；你的選擇會被保留。遊戲不需要網路連線。詳情請見隱私權政策。
```
