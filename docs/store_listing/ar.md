# invade.io — Google Play (العربية)

## اسم التطبيق (9/30)

```
invade.io
```

## الوصف المختصر

```
اغزو الأراضي قاعدة بقاعدة. استراتيجية سريعة، دون اتصال، بلا إعلانات.
```

## الوصف الكامل

```
invade.io لعبة استراتيجية سريعة للسيطرة على الأراضي: اختر قاعدة، اسحب إصبعك، وستنطلق قواتك إلى القاعدة التالية. خمس ثوانٍ للفهم، و30 مستوى حملة، وأكثر من 100 جبهة غزو.

الخريطة هي العالم الحقيقي بسواحله وحدوده وأكثر من ألف مدينة. لكل قارة قواعدها الخاصة: العواصم، المصانع، الأدغال، الواحات، الحصون والطرق البحرية. أكمل الحملة لتفتح غزوات إقليمية بثلاث جبهات ونجوم وزعيم أخير.

وتنتظرك تحديات يومية بقواعد متغيرة، وغزو حر في بعثات من خمس مناطق. العب دون اتصال، بلا إعلانات أو مشتريات: الذهب يُكسب باللعب. 15 لغة، سمتان فاتحة وداكنة، لوحة ألوان لعمى الألوان، حركة مخففة واهتزاز قابل للضبط.
```
