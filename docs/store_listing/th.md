## Short description

```
พิชิตแผนที่โลกจริง เกมกลยุทธ์ยึดดินแดนแบบออฟไลน์ ไม่มีโฆษณา
```

## Full description

```
เปลี่ยนฐานเดียวให้กลายเป็นการพิชิตทั้งทวีป

invade.io เป็นเกมกลยุทธ์ยึดดินแดนแบบออฟไลน์สำหรับผู้เล่นคนเดียว เล่นบนแผนที่โลกจริง ลากระหว่างฐานเพื่อส่งกำลังพล รวมกำลังเข้าด้วยกัน และตัดสินใจว่าจะโจมตีหรือถอยทัพเมื่อไร การควบคุมที่เรียบง่ายทำให้ทุกการเคลื่อนไหวอยู่ในมือคุณ

ทุกการเคลื่อนไหวมีความหมาย
ยึดโรงงานเพื่อเกณฑ์กำลังพลได้เร็วขึ้น รักษาเมืองหลวงเชิงยุทธศาสตร์ และฝ่าแนวป้องกันที่แข็งแกร่ง แต่ละทวีปมีป่าดิบ โอเอซิส เส้นทางทะเล และบอสที่มีกำลังเสริม ปาดผ่านหลายฐานของคุณในครั้งเดียว หรือตัดเส้นทางเพื่อเรียกกองทัพกลับ

แคมเปญ และอะไรอีกมากมาย
ลุยแคมเปญ 30 ด่านใน 6 ทวีป ผ่านแคมเปญของแต่ละทวีปเพื่อปลดล็อกการบุกรายภูมิภาค: 59 ภูมิภาค 177 แนวรบ และดาวให้เก็บ ผ่านภูมิภาคเพื่อรับทอง และรับรางวัลตกแต่งเมื่อผ่านแต่ละทวีป

วิธีพิชิตที่หลากหลายกว่าเดิม
ออกการเดินทัพแบบพิชิตอิสระ: แต่ละครั้งมีห้าภูมิภาคและปิดท้ายด้วยบอส รับความท้าทายรายวันที่กฎเปลี่ยนไปทุกวัน เริ่มด้วยกำลังเท่ากัน และไม่มีการอัปเกรดการต่อสู้ ทำลายสถิติส่วนตัว และคัดลอกการ์ดผลลัพธ์ไปแชร์ให้เพื่อน ความท้าทายรายวันเล่นในเครื่อง ไม่ใช่การแข่งกับผู้เล่นจริง

เก่งขึ้นจากการเล่น
อัปเกรดกองทหารรักษาการณ์ การเกณฑ์ทหาร ความเร็วเดินทัพ และรางวัลทอง เลื่อนยศ สะสมเมืองจากแคมเปญไว้ในสมุดแผนที่ และปลดล็อก 23 ความสำเร็จ ปลดล็อกสีกองทัพ รูปทรงฐาน สไตล์กำลังพล และธีมแผนที่ ไอเทมรูปลักษณ์เปลี่ยนแค่หน้าตาของกองทัพ ไม่ได้เพิ่มพลังต่อสู้

เล่นในแบบของคุณ
• เล่นออฟไลน์ ไม่มีโฆษณา และไม่มีการซื้อในแอป ทองได้มาจากการเล่น
• {count} ภาษา: {languages} ภาษาอาหรับมีอินเทอร์เฟซแบบขวาไปซ้าย
• ธีมสว่างและมืด ปรับขนาดข้อความได้ โทนสีสำหรับผู้ตาบอดสี ลดการเคลื่อนไหว ความคมชัดของแผนที่ ความเร็วเกม และการสั่นตอบสนอง
• ไม่ต้องมีบัญชี ความคืบหน้าอยู่ในอุปกรณ์ของคุณ ส่งออกและนำเข้าข้อมูลสำรองได้ ไม่มีการบันทึกบนคลาวด์
```
