# invade.io — Google Play（日本語）

## アプリ名 (9/30)

```
invade.io
```

## 短い説明

```
拠点を一つずつ奪って領土を征服。高速ストラテジー、オフライン対応、広告なし。
```

## 詳細な説明

```
invade.io は、拠点を選んで指でなぞり、部隊を次の拠点へ進める高速な領土ストラテジーゲームです。5秒で理解でき、30のキャンペーンステージと100以上の侵攻戦線を攻略できます。

地図は実在の世界。海岸線、国境、1000以上の実在都市を舞台に、各大陸ごとのルールが加わります。首都、工場、ジャングル、オアシス、要塞、海路。キャンペーンをクリアすると、3つの戦線、星、最終ボスを備えた地域侵攻が解放されます。

ルールが変わるデイリーチャレンジや、5地域を巡る自由征服も用意。オフラインで遊べ、広告も課金もありません。ゴールドはプレイで獲得できます。15言語、ライト/ダークテーマ、色覚多様性パレット、モーション軽減、振動調整に対応。
```
