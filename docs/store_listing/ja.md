# invade.io — Google Play (Japanese)

## App name

```
invade.io: 領土戦略
```

## Short description

```
現実の地図で領土を征服。オフラインで楽しめる広告なしの戦略ゲーム
```

## Full description

```
ひとつの拠点から、6大陸へと征服を広げよう。

invade.ioは、現実の地図を舞台にしたオフラインの1人用領土戦略ゲーム。拠点から拠点へドラッグして部隊を送り、味方の戦力を集め、攻撃と撤退のタイミングを見極めましょう。

一手ごとに変わる戦況
工場を占領して徴兵を速め、重要な首都を確保し、要塞を突破。ジャングル、オアシス、海路、増援を受けるボスなど、大陸ごとに異なる戦術が求められます。複数の味方拠点をひと筆で結んだり、進軍ルートを切って部隊を呼び戻したりできます。

キャンペーンの先にも続く征服
6大陸に広がる30のキャンペーンステージに挑戦。各大陸のキャンペーンをクリアすると、その大陸の地域侵攻が解放されます。36の地域と108の戦線でスターを獲得し、地域の制覇でゴールド、大陸の制覇で外観アイテムを手に入れましょう。

自由征服では、1回の遠征で5つの地域を進み、最後にボスと戦います。日替わりのルールで遊ぶデイリーチャレンジは、戦闘アップグレードなしの同じ初期戦力で挑戦。自己ベストを更新し、結果カードをコピーして友達に共有できます。対戦は端末内で進行し、リアルタイムのプレイヤー対戦ではありません。

プレイして育てる自分の軍
守備隊、徴兵、行軍速度、ゴールド報酬を強化。ランクを上げ、地図帳にキャンペーンの都市を集め、20の実績を達成しましょう。軍の色、拠点の形、部隊スタイル、マップテーマも解放できます。外観アイテムは見た目だけを変え、戦闘力には影響しません。

自分に合った遊び方
• オフライン対応、広告なし、アプリ内購入なし。ゴールドはプレイで獲得できます。
• 日本語を含む15言語に対応。アラビア語は右から左の表示にも対応しています。
• ライト／ダークテーマ、文字サイズ、色覚サポート、動きを減らす設定、マップのコントラスト、ゲーム速度、振動を調整できます。
• アカウント不要。進行状況は端末に保存され、バックアップの書き出し・読み込みが可能です。クラウドセーブはありません。

プライバシー
使用状況の統計とクラッシュレポートは任意の機能で、このバージョンでは初期状態で有効です。「設定 → プライバシー」で個別に無効にでき、保存済みの選択は維持されます。ゲームプレイ自体にインターネット接続は必要ありません。詳しくはプライバシーポリシーをご確認ください。
```
