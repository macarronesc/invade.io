# invade.io — Google Play（简体中文）

## 应用名称 (9/30)

```
invade.io
```

## 简短说明

```
逐个基地征服领土。快节奏策略，离线可玩，无广告。
```

## 完整说明

```
invade.io 是一款快节奏的领土策略游戏：选择一个基地，拖动手指，部队就会向下一座基地进军。五秒上手，30 个战役关卡，100 多个入侵前线等你征服。

地图就是真实世界，包含海岸线、边界和一千多座城市。每个大陆都有专属规则：首都、工厂、丛林、绿洲、堡垒和海上航线。完成战役即可解锁三大前线的区域入侵，赢取星星并挑战最终首领。

还有规则轮换的每日挑战，以及五区域远征中的自由征服。离线可玩，无广告、无内购：金币靠游戏获得。支持 15 种语言、浅色与深色主题、色盲调色板、减少动态效果和可调振动。
```
