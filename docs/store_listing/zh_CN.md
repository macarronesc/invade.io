# invade.io — Google Play（简体中文）

## 应用名称

```
invade.io：领土策略
```

## 简短说明

```
在真实世界地图上征服领土。离线策略，无广告
```

## 完整说明

```
从一座基地出发，逐步征服六大洲。

invade.io 是一款以真实世界地图为舞台的离线单人领土策略游戏。在基地之间拖动即可派兵，集结友军，选择进攻或撤退的时机。

每一步都关乎胜负
占领工厂以加速招募，控制重要首府，突破堡垒防线。丛林、绿洲、海路和拥有增援的首领，让不同大陆各具战术变化。一笔连接多座友军基地，也能切断行军路线召回部队。

战役之外，还有更多征服目标
挑战横跨六大洲的 30 个战役关卡。完成某个大陆的战役后，即可解锁该大陆的区域入侵。共有 36 个地区、108 条战线和星级目标，完成地区可获得金币，征服大陆可解锁外观奖励。

自由征服模式中，每次远征包含五个地区，并以首领战收尾。每日挑战轮换规则，所有玩家使用相同初始兵力，不应用战斗升级。突破个人纪录，复制战报卡与朋友分享。每日挑战在本机运行，不是实时玩家对战。

靠游玩积累实力
升级驻军、招募、行军速度和金币奖励。提升军衔，在图集中收集战役城市，完成 20 项成就。解锁军队颜色、基地形状、部队风格和地图主题。外观只改变样式，不增强战斗力。

按自己的方式游玩
• 离线可玩，无广告、无应用内购买，金币靠游玩获得。
• 支持 15 种语言，包括简体中文和从右向左显示的阿拉伯语界面。
• 可调整浅色或深色主题、文字大小、色觉辅助配色、减少动态效果、地图对比度、游戏速度和触觉反馈。
• 无需账号。进度保存在设备上，可导出或导入备份；没有云存档。

隐私
使用统计与崩溃报告均为可选功能，在本版本中默认开启。可在“设置 → 隐私”中分别关闭，已有选择会保留。游玩本身无需联网。详情请查看隐私政策。
```
