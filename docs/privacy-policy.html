invade.io — Política de privacidad

Última actualización: 22 de octubre de 2026

Resumen: invade.io no tiene cuentas ni pide nombres o correos. Las estadísticas de uso y los informes de fallos son opcionales, están desactivados de forma predeterminada y sólo se envían si activas cada opción en Ajustes → Privacidad.

1. Qué datos se envían

Si activas la opción correspondiente, el juego puede enviar:

  • Estadísticas de uso: nivel o modo jugado, resultado, duración, estrellas, intentos, mejoras compradas, recompensas, pestañas abiertas, idioma, versión de la app, sistema operativo, modelo de dispositivo, versión del SDK, estado de depuración, país aproximado y un identificador temporal de sesión para agrupar eventos. El juego no envía nombre, correo, contactos, ubicación precisa, identificadores de publicidad ni identificadores persistentes de usuario o dispositivo.
  • Informes de fallos: mensaje y traza del error, versión de la app y del sistema, modelo de dispositivo y las últimas acciones dentro del juego (por ejemplo, el nivel que se estaba jugando). No se asocian a una cuenta del juego.

El juego no incluye publicidad, redes sociales ni seguimiento entre aplicaciones. No crea perfiles de usuario ni vende datos.

Para enviar esta información la app declara el permiso INTERNET y consulta el estado de la conexión con ACCESS_NETWORK_STATE. El único otro permiso es VIBRATE, que hace vibrar el teléfono al dar órdenes.

2. Qué se guarda y dónde

Tu progreso (oro, mejoras, niveles superados, ajustes, idioma y logros) se guarda solo en tu dispositivo, en el almacenamiento privado que Android o iOS reservan a la aplicación.

  • En Ajustes → Datos puedes exportar una copia (invade-backup.json) al lugar que tú elijas, e importarla después. Ese archivo lo eliges y lo controlas tú; contiene el progreso del juego y ningún dato personal.
  • Si desinstalas el juego, el sistema borra esos datos. Sin la copia exportada, el progreso no se puede recuperar: no existe ninguna copia en servidores nuestros.

3. Quién procesa los datos

Para no mantener servidores propios, el juego usa dos proveedores que actúan como encargados del tratamiento:

  • Aptabase (estadísticas de uso; esta app usa el endpoint de la Unión Europea): política de privacidad · acuerdo de tratamiento. Conserva los datos hasta 5 años.
  • Sentry (informes de fallos, Functional Software, Inc.; esta app usa el endpoint de ingestión de la Unión Europea): política de privacidad · acuerdo de tratamiento. En el plan gratuito conserva los eventos 30 días.

Ambos proveedores reciben los datos cifrados en tránsito y no los usan para publicidad ni para crear perfiles. Las solicitudes de red incluyen la dirección IP de conexión; Aptabase puede usarla para inferir el país aproximado y Sentry puede recibirla junto con un informe de fallo. El juego no envía un identificador de cuenta o dispositivo persistente. Revisa las políticas y acuerdos de cada proveedor para conocer sus prácticas de retención y las transferencias aplicables.

4. Control y base legal

Las dos opciones están desactivadas al instalar el juego. Al activarlas, autorizas por separado el envío de estadísticas de uso o informes de fallos para mejorar el juego. No se usan para publicidad ni para tomar decisiones automatizadas sobre ti. Los requisitos legales pueden variar según tu región.

En Ajustes → Privacidad puedes retirar esa autorización en cualquier momento. Al desactivar una opción, el juego descarta los eventos de analítica que aún no se habían enviado y deja de recopilar nuevos datos para esa opción. Una solicitud de red que ya estuviera en curso podría completarse. Los datos que los proveedores ya recibieron no pueden localizarse ni borrarse individualmente mediante el juego, porque no se envía un identificador de cuenta. Para consultas o solicitudes, escribe al correo de contacto.

5. Menores

El juego no está dirigido a menores de 13 años. No hay cuentas y el juego no pide que introduzcas datos personales. Las estadísticas y los informes de fallos permanecen desactivados hasta que se activen en Ajustes → Privacidad.

6. Cambios

Si una versión futura añade funciones que recojan datos personales (por ejemplo, guardado en la nube o clasificaciones con cuenta), esta política se actualizará antes de publicarla y se pedirá el consentimiento correspondiente.

invade.io — Privacy policy

Last updated: 22 October 2026

Summary: invade.io has no accounts and does not ask for names or email addresses. Usage statistics and crash reports are optional, off by default, and sent only if you enable each option in Settings → Privacy.

1. What is sent

When you enable the corresponding option, the game may send:

  • Usage statistics: level or mode played, result, duration, stars, attempts, upgrades bought, rewards, tabs opened, language, app version, operating system, device model, SDK version, debug state, approximate country and a temporary session identifier used to group events. The game does not send your name, email, contacts, precise location, advertising identifiers or persistent user or device identifiers.
  • Crash reports: error message and stack trace, app and OS version, device model and the last actions inside the game (for example, the level being played). They are not linked to a game account.

The game contains no advertising, social media or cross-app tracking. It does not build user profiles or sell data.

To send this information the app declares the INTERNET permission and checks the connection state with ACCESS_NETWORK_STATE. The only other permission is VIBRATE, used to buzz the phone when you give orders.

2. What is stored and where

Your progress (gold, upgrades, completed levels, settings, language and achievements) is stored only on your device, in the private storage Android or iOS reserves for the app.

  • In Settings → Data you can export a copy (invade-backup.json) wherever you choose and import it later. That file is yours: it contains the same game progress and no personal data.
  • Uninstalling the game erases that data. Without your exported copy the progress cannot be recovered: there is no copy on any server of ours.

3. Who processes the data

To avoid running our own servers, the game uses two providers acting as data processors:

  • Aptabase (usage statistics; this app uses its European Union endpoint): privacy policy · data processing agreement. It retains data for up to 5 years.
  • Sentry (crash reports, Functional Software, Inc.; this app uses its European Union ingest endpoint): privacy policy · data processing agreement. On the free plan it retains events for 30 days.

Both providers receive the data encrypted in transit and do not use it for advertising or to build profiles. Network requests include the connection IP address; Aptabase may use it to infer approximate country, and Sentry may receive it with a crash report. The game does not send a persistent account or device identifier. See each provider's policies and agreements for retention and applicable transfers.

4. Control and legal basis

Both options are off when you install the game. Enabling them separately authorizes the game to send usage statistics or crash reports to help improve the game. They are not used for advertising or automated decisions about you. Legal requirements may vary by region.

In Settings → Privacy you can withdraw that choice at any time. Turning an option off discards analytics events that have not yet been sent and stops collecting new data for that option. A network request already in progress may still complete. Data already received by a provider cannot be located or deleted individually through the game because no account identifier is sent. For questions or requests, use the contact email.

5. Children

The game is not directed at children under 13. There are no accounts, and the game does not ask you to enter personal data. Usage statistics and crash reports remain off until enabled in Settings → Privacy.

6. Changes

If a future version adds features that collect personal data (for example, cloud save or online rankings with an account), this policy will be updated before publishing it and the corresponding consent will be requested.
