Privacy policy

Last updated: 28 October 2026

Summary: invade.io has no accounts and does not ask for names or email addresses. Usage statistics and crash reports are optional and enabled by default. You can turn either option off in Settings → Privacy; saved choices are respected, including options disabled in previous versions.

1. What is sent

While the corresponding option is enabled, the game may send:

  • Usage statistics: level or mode played, result, duration, stars, attempts, upgrades bought, rewards, tabs opened, language, app version, operating system, device model, SDK version, debug state, approximate country and a temporary session identifier used to group events. The game does not send your name, email, contacts, precise location, advertising identifiers or persistent user or device identifiers.
  • Crash reports: error message and stack trace, app and OS version, device model and the last actions inside the game (for example, the level being played). They are not linked to a game account.

The game contains no advertising, social media or cross-app tracking. It does not build user profiles or sell data.

To send this information the app declares the INTERNET permission and checks the connection state with ACCESS_NETWORK_STATE. The only other permission is VIBRATE, used to buzz the phone when you give orders.

2. What is stored and where

Your progress (gold, upgrades, completed levels, settings, language and achievements) is stored only on your device, in the private storage Android or iOS reserves for the app.

  • In Settings → Data you can export a copy (invade-backup.json) wherever you choose and import it later. That file is yours: it contains the same game progress and no personal data.
  • Uninstalling the game erases that data. Without your exported copy the progress cannot be recovered: there is no copy on any server of ours.

3. Who processes the data

To avoid running our own servers, the game uses two providers acting as data processors:

  • Aptabase (usage statistics; this app uses its European Union endpoint): privacy policy · data processing agreement. It retains data for up to 5 years.
  • Sentry (crash reports, Functional Software, Inc.; this app uses its European Union ingest endpoint): privacy policy · data processing agreement. On the free plan it retains events for 30 days.

Both providers receive the data encrypted in transit and do not use it for advertising or to build profiles. Network requests include the connection IP address; Aptabase may use it to infer approximate country, and Sentry may receive it with a crash report. The game does not send a persistent account or device identifier. See each provider's policies and agreements for retention and applicable transfers.

4. Control and legal requirements

Both options are on when you install the game and also apply to older saves without these options. Existing saved preferences are preserved. Data is used to improve the game, not for advertising or automated decisions about you. An enabled default does not constitute consent; legal requirements may vary by region.

In Settings → Privacy you can disable either option at any time. Turning an option off discards analytics events that have not yet been sent and stops collecting new data for that option. A network request already in progress may still complete. Data already received by a provider cannot be located or deleted individually through the game because no account identifier is sent. For questions or requests, use the contact email.

5. Children

The game is not directed at children under 13. There are no accounts, and the game does not ask you to enter personal data. Usage statistics and crash reports follow the settings described above and can be disabled separately in Settings → Privacy.

6. Changes

If a future version adds features that collect personal data (for example, cloud save or online rankings with an account), this policy will be updated before publishing it and the corresponding consent will be requested.
